## 5. Open-source projects

All on [github.com/mhatem5351](https://github.com/mhatem5351).

### LLM tooling (2026, MIT licence)
- **[staged-llm-evaluator](https://github.com/mhatem5351/staged-llm-evaluator)**: a replayable LangGraph pipeline that
  grades LLM outputs in separate **quality, safety and retry** stages; the final pass / review / fail **verdict is
  computed in plain Python, not by the model**. Every LLM call is logged with its stage, model and a SHA-256 hash of
  the prompt; a standalone validator re-checks all artifacts without calling a model; judge evidence must be an exact
  quote from the output (unverifiable quality evidence is nulled, unverifiable safety findings are dropped); the
  retry stage never sees scores. Offline tests with a stubbed client run in GitHub Actions
  on Python 3.11 and 3.13. Stack: Python, LangGraph, OpenAI API, pytest.
- **[prompt-reliability-harness](https://github.com/mhatem5351/prompt-reliability-harness)**: measures how consistently
  an LLM answers when the same question is paraphrased, misspelled, padded with noise, reordered or given
  distractors. Invariance and perturbation tests; exact, regex and embedding-similarity scoring; consistency and flip
  rate. Result (gpt-4o-mini, 3 runs per variant): regex correctness 1.00, yet mean consistency 0.49, mostly from the
  same answer worded differently.
- **[rag-answering-service](https://github.com/mhatem5351/rag-answering-service)**: a small retrieval-only FastAPI
  service with OpenAI embeddings, cosine vs dot-product indexes compared side by side (`/compare`), a denylist
  guardrail against prompt injection, SQL/XSS probes and oversized queries, and P50/P95/P99 latency plus hit-rate
  metrics (`/metrics`). No generation step by design.

### ML and NLP (2022)
